# 今天去哪汪？｜广州周末随机转盘 — 设计说明

## 目标

制作一个可公开分享、手机优先的静态 Web App，帮助用户快速决定广州周末去哪里。核心体验是 SVG 转盘的仪式感，而不是旅行信息门户。

## 体验与视觉

- 视觉采用奶油色手帐拼贴：`#FFF9F1` 背景、低饱和黄/粉/绿/蓝色纸片，以及黑色微不规则线条。
- 首页采用拼贴构图，但大转盘始终是最大视觉元素。顶部只保留产品名、短副标题和趴着的小狗。
- 小狗为原创 SVG 线稿角色（圆脑袋、豆豆眼、短腿、白色身体与少量腮红），独立存放在 `src/assets/dogs/`，可替换而不影响逻辑；不使用或仿制受版权保护的「线条小狗」官方角色与素材。
- 角色状态覆盖：默认趴着、开心、思考、转圈、指向、举牌、吃东西、散步。它会随筛选、旋转与结果变化，而非仅作为装饰。
- 尊重 `prefers-reduced-motion`：减少转盘圈数、弹跳和碎屑效果。

## 使用流程

1. 用户打开页面，偏好、预算、室内外均不预选；可直接开转。
2. 用户可按类别多选、预算、室内/户外筛选；结果根据条件即时更新。
3. 点击开转时，应用从匹配集生成 8 个候选，并在动画前选定真实的结果和目标旋转角度。
4. SVG 转盘旋转 3–5 秒后准确将目标扇区对准固定指针，停止时轻微回弹并弹出结果底部抽屉。
5. 结果抽屉显示活动、区域、参考人均费用、时长、场景、交通、推荐理由及贴士；用户可收藏、分享或再转。

## 内容模型

- `activities.ts` 维护约 60 条稳定且适合普通年轻人的广州周末选项，覆盖天河、越秀、海珠、荔湾、番禺、白云、黄埔和其他区域。
- 分类：`art`、`outdoor`、`food`、`show`、`market`、`experience`。
- 每项包括：稳定 ID、全名/短名、分类、区域、参考人均费用/标签、时长、`indoor | outdoor | mixed`、标签、emoji、推荐理由、可选贴士、地图关键词、公共交通提示，以及动态活动标记。
- 数据中不绑定时效性或经营状态不确定的具体活动；演出、市集使用场景型建议，并在 UI 提示出发前确认当周安排。
- 每一项活动均提供 `transport` 与 `budget`，方便结果卡片给出可执行的出行信息。

## 实现架构

- React + TypeScript strict + Vite；不引入大型依赖。
- `components/`：Header、FilterPanel、Wheel、DogMascot、ResultSheet、FavoritesSheet、ShareButton、Confetti。
- `data/activities.ts`：内容数据与类型；`utils/random.ts`：筛选、候选生成、目标角度；`utils/storage.ts`：收藏持久化。
- `hooks/useWheel.ts` 负责防重复点击、旋转状态与结果一致性；`hooks/useFavorites.ts` 负责 LocalStorage 收藏。
- SVG 转盘依据候选数组绘制扇区；指针固定。角度计算会让目标落在扇区中央，且连续抽取规避上次结果。

## 容错与交互细节

- 条件组合无匹配项时显示原创小狗 empty state，并可一键清空筛选。
- 旋转期间禁止再次启动；按钮展示“命运选择中……”。
- 第 5 次与第 10 次连续转动，以及连续三次吃喝结果触发仅提示、不干扰随机逻辑的彩蛋。
- 分享优先使用 `navigator.share()`，否则复制包含结果和当前链接的文本并提示成功。
- 所有交互元素提供 `aria-label` 和键盘可达性；色彩与文字保持基础可读对比度。

## 测试与发布

- Vitest 测试筛选、候选合法性、防连续重复、目标扇区角度、收藏的读写和移除。
- 组件测试覆盖旋转禁用态、结果与选中项一致性、筛选和 empty state。
- 执行生产构建，并以 Vite Preview 在 375px、390px、430px 与桌面视口作实际检查。
- 以 GitHub Actions 在 `main` push 后构建并部署 GitHub Pages；Vite `base` 由仓库名配置，避免 Project Pages 静态资源 404。

## 验收标准

- 可运行、移动端布局良好；真实 SVG 转盘可旋转且结果准确。
- 筛选、结果抽屉、再转、收藏、分享、empty state 和彩蛋有效。
- 包含约 60 条活动、六类分类、参考费用及交通提示。
- 测试和 `npm run build` 通过，仓库公开推送，线上 Pages 可访问且资源无 404。
