# 更多城市与周末趣味互动

## 目标与范围

保留鱼丸手账风格、所有既有活动和五城功能，扩充常驻选项与地区。默认新增杭州、南京、成都、重庆；现有五城增加覆盖不足行政区的活动。新增城市必须满足现有常驻池、官方参考来源、官方适配器及 fixture 门槛，不能伪造实时数据。

## 内容与加载

常驻内容继续在各自城市的 TypeScript 模块维护。构建时生成可校验的紧凑城市 JSON，前端只请求所选城市，保存同城有效缓存；切城时隔离请求、忽略旧响应。JSON采用共享字段/字符串表示并无损还原完整活动，不删除旧内容。首次加载有明确状态，缓存失效或首次请求失败可重试，不显示其他城市内容；已有缓存支持离线回退。旧广州收藏按需加载广州数据进行迁移，保留未知收藏与旧键，迁移期间新增或删除收藏不能丢失。

原有 JS/CSS/图片预算配置和检查逻辑保持不变。新增检查约束“全部 JS + 最大单城常驻 JSON”不超过原370000字节 JS 上限，并报告总内容字节，避免仅通过移动文件绕过体积约束。

## 趣味与视觉

新增“今日玩法”快捷情境：随便逛逛、低预算出门、雨天不无聊、一起热闹、拍照散步、夜晚漫游；点击后替换筛选，沿用现有过滤器，不做隐形排除。转盘过程中禁用玩法切换。

结果页增加按活动类别给出的轻量“周末小任务”，可换一个、标记完成；以活动ID隔离，切换结果时清空完成状态，不冒充官方活动或持久化行程。

背景提供“晴日/暮色/夜游”三种主题，缓慢移动的云朵、光斑与手绘装饰；用户可暂停动态并记住偏好。所有装饰不拦截操作、从无障碍树隐藏；系统减少动画生效时停止背景、转盘装饰与交互动画。使用CSS transform/opacity，不新增大图、视频、动画库或持续的React逐帧渲染。

## 验证

保留旧357项逐字段、顺序、ID及legacy映射。覆盖新城内容/来源门槛、加载竞态、离线缓存、失败重试、旧收藏迁移与并发操作；验证快捷玩法、小任务、主题持久化和减少动画。运行全部单元、来源fixture、Lint、TypeScript、预算及生产子路径E2E，多视口和axe。沿用独立PR、CI和Rebase合入流程。既有线上图片取消请求监控问题单独识别，不隐瞒失败或放宽资源失败监控。
